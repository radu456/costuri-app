# Atelier de lectură – aplicații PWA

Șase aplicații interactive pentru lecțiile 9–14, optimizate pentru tablete și copii de 6–8 ani. Fișierele sunt publicate în repository-ul GitHub `radu456/costuri-app`. Linkurile de utilizare sunt generate prin HTML Preview și se află în pachetul local de QR-uri.

Codurile QR sunt statice și nu au termen tehnic de expirare; ele conțin direct linkul aplicației. Linkurile funcționează cât timp repository-ul GitHub rămâne public și serviciul HTML Preview este disponibil.
